# java-lotto-precourse

## 📌 기능 정리

1️ 로또 구입 금액 입력 받기
- 구입 금액 입력 받기
- 구입 금액이 정수형으로 변환 불가능하면 예외 발생
- 구입 금액이 1000원으로 나누어 떨어지지 않으면 예외 발생
- 구입 금액이 0 이하면 예외 발생

2️ 로또 개수 계산하기
- 입력받은 구입 금액을 기반으로 로또 구매 개수 계산하기
- 0개인 경우 예외 발생

3️⃣ 구입 개수 출력하기
- 구매한 로또 개수를 출력

4️⃣ 로또 발행하기
- 각 로또는 1~45 사이의 중복되지 않는 6개의 정수로 구성
- 구입 개수만큼 반복해서 로또 발행
- 각 로또 번호는 오름차순 정렬

- 6개의 번호 생성 여부 확인
- 중복 번호 없는지 확인
- 로또 번호가 1~45 범위 내에 있는지 확인
- 오름차순 정렬 확인

5️⃣ 로또 번호 출력하기
- 발행된 모든 로또 번호를 오름차순으로 출력

6️⃣ 당첨 번호 입력 받기
- 쉼표(,)로 구분된 숫자 6개 입력받기
- 입력이 숫자가 아닌 경우 예외 발생
- 개수가 6개가 아닐 경우 예외 발생
- 1~45 범위를 벗어나면 예외 발생
- 중복된 숫자가 존재하면 예외 발생

7️⃣ 보너스 번호 입력 받기
- 보너스 번호 한 개 입력 받기
- 1~45 범위를 벗어나면 예외 발생
- 당첨 번호와 중복될 경우 예외 발생

8️⃣ 당첨 확인하기
- 각 구매 로또를 당첨 번호와 비교하여 일치 개수 계산
- 일치 개수와 보너스 번호 일치 여부로 등수 판별
- 모든 로또 결과 집계

9️⃣ 당첨 내역 출력
- 형식을 지켜서 당첨 내역 출력

- 총 당첨 금액 계산
- 수익률 계산
- 소수점 둘째 자리에서 반올림
